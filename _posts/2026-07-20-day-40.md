what_i_learned: |
  Today started with our research lab session, where I began running a new and updated notebook shared by our graduate mentor. The notebook focused on creating a cleaner and more reliable evaluation pipeline for the BIDMC dataset.
  One major improvement was dividing the data into patient-disjoint training, validation, and testing sets. This ensured that windows from the same patient could not appear in multiple partitions. I also prepared synchronized ten-second ECG, PPG, and respiratory windows so that each multimodal sample represented the same recording period.
  I generated six domains: ECG time, frequency, and time-frequency, along with the same three representations for PPG. pyCFD 3.0 evaluated all fifteen possible domain pairs using fusion gain, permutation testing, confidence intervals, redundancy, and the CFD Index.
  After rerunning the experiment with more bootstrap samples and permutations, ECG frequency and PPG frequency became the highest-ranked qualifying pair. This pair had a positive fusion gain, a significant p-value, and a confidence interval above zero. I also learned that increasing bootstrap samples and permutations does not improve the model itself. It makes the statistical estimates more stable and precise.

blockers: |
  One challenge was understanding why the optimal pair changed between runs. The earlier result selected PPG frequency and PPG time-frequency, while the updated run selected ECG frequency and PPG frequency. This showed me that random initialization and statistical resampling can affect experimental rankings.
  I also encountered an error when locking the selected pair. The code correctly displayed ECG_Freq_vs_PPG_Freq, but the parsing function left an extra underscore before PPG_Freq. This caused the code to incorrectly reject the result as a non-ECG–PPG pair. I fixed the issue by using the cleaner domains column and improving the pair-name parser.

reflection: |
  Today showed me that reliable research requires more than producing model results. Patient separation, synchronized signals, statistical testing, and careful validation all affect whether the final conclusions are trustworthy.
  I also learned not to accept a result simply because it matches my expectations. Even though the new ECG and PPG pair was encouraging, it was still important to verify that it met the predefined selection rules and that the test patients remained untouched.
  Overall, today was a productive day of debugging, validation, and understanding how small implementation details can affect a larger experimental pipeline.
